# 🐾 Patas do Bem

O **Patas do Bem** será uma plataforma web desenvolvida com o objetivo de conectar **ONGs de proteção animal, voluntários e pessoas interessadas em adoção ou doações**, facilitando a divulgação de animais que precisam de um novo lar e fortalecendo a rede de apoio à causa animal.

O projeto será desenvolvido como parte das atividades acadêmicas da **Faculdade Santa Marcelina – Muriaé**, buscando aplicar conceitos de desenvolvimento web, organização de software e boas práticas de programação.

---

## 🎯 Objetivo do Projeto

A plataforma será desenvolvida para:

* Divulgar **ONGs e projetos de proteção animal**
* Facilitar o processo de **adoção responsável**
* Permitir **doações** para apoiar instituições
* Incentivar o **voluntariado**
* Centralizar informações sobre **animais disponíveis para adoção**

O sistema buscará aproximar a sociedade das organizações que atuam no resgate e cuidado de animais.

---

## 💻 Tecnologias que serão utilizadas

Durante o desenvolvimento do projeto, serão utilizadas as seguintes tecnologias:

* **PHP**
* **HTML5**
* **CSS3**
* **JavaScript**
* **Bootstrap**
* **MySQL**
* **Arquitetura MVC**

Além disso, o projeto seguirá boas práticas de organização de código e versionamento utilizando **Git e GitHub**.

---

## 🧩 Funcionalidades previstas

O sistema será desenvolvido para oferecer funcionalidades como:

* Página inicial com apresentação do projeto
* Listagem de **ONGs cadastradas**
* Área de **adoção de animais**
* Sistema de **doações**
* Cadastro de **voluntários**
* Área de **login e cadastro de usuários**
* Interface responsiva para diferentes dispositivos

## ❤️ Sobre a causa

A iniciativa busca incentivar a **adoção responsável** e fortalecer o trabalho de organizações que dedicam seus esforços ao cuidado e proteção dos animais.

Cada adoção representa uma nova oportunidade de vida para um animal que precisa de um lar.
